# 一、研究定位与核心问题

## 1.1 背景

CCS'25 工作证明：在线 HD map construction model 在 asymmetric road scenes（fork、merge、one-side diverging）中存在 **symmetry bias**。攻击者可在路侧部署 flashlight 或 adversarial patch，触发 road straightening 或 early turn，影响下游规划安全。该工作的主要研究对象是**单帧** online map construction model，包括 MapTR 和 VectorMapNet。

随着自动驾驶系统逐步采用 **streaming online map construction**（代表模型：StreamMapNet），时序状态（temporal state）被引入预测流程，包括：
- **Streaming Query Propagation**：上一帧的 instance queries 被传播到下一帧；
- **Historical BEV Fusion**：历史帧的 BEV features 被融合入当前帧编码。

这种时序状态是一把双刃剑：

> 它既可能将瞬时攻击造成的错误带入未来帧（**temporal residue**），  
> 也可能通过 confidence filtering 和 clean observations 抑制瞬时错误（**temporal self-healing**）。

## 1.2 核心研究问题

> **一次物理可行的、在帧 t 发生的 transient perturbation，是否会在 streaming online HD map construction model 的 temporal state 中产生持续到帧 t+1 及以后的错误残留？**

这不是一个必然成立的命题，需要通过实验验证。

## 1.3 与 CCS'25 的明确区分

| 维度 | CCS'25 | 本文 |
|------|--------|------|
| 研究对象 | 单帧模型（MapTR / VectorMapNet） | Streaming 模型（StreamMapNet），MapTR 作单帧对照 |
| 攻击目标 | 单帧 map corruption | 攻击停止后的 temporal residue |
| 核心机制 | 同帧内 symmetry bias（cross-element attention） | Temporal state contamination vs. self-healing |
| 主要指标 | AP drop, UGR, UPTR | Paired RecoveryRatio, RFC, APD, AUC_residue, DID |
| 物理攻击 | Flashlight + adversarial patch | Camera Blinding 为主，patch 为补充 |
| 贡献类型 | 新攻击发现 | Streaming map 时序安全分析 |

# 二、研究假设

## H1：Temporal Residue Hypothesis（主假设）

单帧 Camera Blinding attack 在帧 t 造成的错误 map prediction 可能污染 StreamMapNet 的 temporal state，使 t+1 到 t+L 的 clean 输入帧仍然产生错误预测。

验证指标：

$$\text{RecoveryRatio}_i = \frac{\text{Metric}^{\text{attack}}_{t+i}}{\text{Metric}^{\text{clean}}_{t+i}}$$

若攻击停止后连续 $K=3$ 帧满足 $\text{RecoveryRatio}_i < \tau = 0.9$，则 H1 成立。

## H2：Propagation Channel Hypothesis

若 H1 成立，residue 通过以下一个或多个通道传播：

1. **Streaming Query Propagation**：错误 boundary query 被选中传播；
2. **Historical BEV Fusion**：攻击帧污染的 BEV features 被融合入后续帧；
3. **二者共同作用**。

验证方式：temporal state reset ablation（详见实验组 2）。

## H3：Single-frame Control Hypothesis

MapTR 没有 temporal state，因此不存在从帧 t 传播到帧 t+i 的 state contamination channel。

**注意**：MapTR 的角色是 **single-frame difficulty control**，而非"理想恢复上界"。MapTR 在 t+i 帧上的 clean 表现可能本身就较差（该帧是困难的 asymmetric frame），不应将其用作 StreamMapNet 的恢复参考线。

## H4：Temporal Amplification Hypothesis

连续 N 帧攻击可能造成超过独立 N 次单帧攻击叠加效果的额外损伤。

**注意**：不能用 $\Delta\text{mAP}(N)/\Delta\text{mAP}(1)$ 证明 amplification，原因：
- 连续攻击是在 already-degraded state 上叠加的，与独立单帧攻击的起点不同；
- 必须使用 additive interaction 形式，并控制 reset-state 作为基线。

## H5：Temporal Self-healing Alternative（备选假设）

若 H1 不成立，则本文的主要发现为：

> Streaming online HD map construction exhibits **temporal self-healing** against transient symmetry-bias physical perturbations.

这仍是有价值的发现，但论文定位从攻击论文转为鲁棒性分析论文（详见第三节）。

# 三、两条论文路径

**在启动全量实验之前，必须通过 Phase 0.5 + Phase 1 确定执行哪条路径。**

## 路径 A：H1 成立（Temporal Residue Attack 论文）

**成立条件**（全部满足）：
1. 攻击帧 t 产生明显 target-boundary error（RSS = 1 且 Chamfer delta 显著）；
2. 错误 target query 置信度足够高，且被 propagation 模块选中；
3. median RFC ≥ 2 frames；
4. AUC_residue 在 bootstrap 95% CI 下显著大于 0；
5. reset-all 后 AUC_residue 显著下降（DID 显著）；
6. 至少一种 reset 条件（reset-query 或 reset-BEV）能解释主要 residue 来源。

**论文 Title**：  
*Temporal Residue of Physical Attacks on Streaming Online HD Map Construction*

**核心贡献**：
1. 首次证明 streaming online HD map construction 在 transient physical attacks 下存在 temporal residue；
2. 提出 paired temporal evaluation protocol（RecoveryRatio, RFC, APD, AUC_residue, DID）；
3. 通过 state reset ablation 证明 query propagation 和/或 BEV fusion 是 residue 传播通道；
4. 量化 planner-level safety risk 在 recovery window 内的持续影响；
5. 提供初步 mitigation 策略（可选）。

## 路径 B：H1 不成立（Temporal Self-healing 论文）

**不成立判定**（满足任意一条）：
- wrong target query 置信度过低，未被 propagation 选中；
- median RFC ≤ 1 frame（攻击停止后 t+1 已基本恢复）；
- reset-all 与 keep-state 的 AUC_residue 无显著差异。

**论文 Title**：  
*Temporal Robustness of Streaming Online HD Map Construction under Transient Physical Perturbations*

**核心贡献**：
1. 首次系统分析 streaming online HD map construction 在 transient symmetry-bias perturbations 下的时序鲁棒性；
2. 证明 confidence filtering 在 query propagation 中对瞬时错误具有天然抑制作用；
3. 通过 reset ablation 定量分析 temporal state 对 clean 性能的贡献；
4. 为 streaming map model 安全设计提供指导原则。

# 四、模型与数据集

## 4.1 模型

### MapTR
- **角色**：单帧对照模型（single-frame difficulty control）
- **使用方式**：在本文选出的同一批 target frames 上独立运行，**不引用 CCS'25 Table 2**
- **约束**：使用与 StreamMapNet 实验完全相同的 target frames、attack rendering、evaluation script、planner setting

### StreamMapNet
- **角色**：主要研究对象
- **关注机制**：
  - Streaming Query Propagation（instance query 跨帧传播）
  - Historical BEV Fusion（历史帧 BEV feature 融合）
  - Query matching / confidence filtering（决定哪些 query 被传播）
  - Ego-motion compensation
- **工程要求**：
  - 实现 temporal state reset hook（支持 reset-all / reset-query-only / reset-BEV-only）
  - 实现 query extraction hook（提取 propagated query confidence 和 geometry）
  - 确认 official clean mAP 可复现

### MapTracker（可选，仅策略 B）
仅在主实验完成、结果清晰、时间充足时加入，作为第二 streaming model 验证泛化性。

# 五、Asymmetric Scene 筛选与样本控制

## 5.1 Selection Funnel（必须完整报告）

```
所有 nuScenes val frames（~6000+）
  ↓ 保留有足够 warm-up + recovery 窗口的帧
  ↓ Rule-based curvature 差值筛选
  ↓ VLM 精炼（过滤 false positives）
  ↓ 攻击源在帧 t 可见（VPA > 阈值）
  ↓ Clean-quality filter
  ↓ Scene-level independence sampling
  ↓ 最终评估帧集
```

每一步报告：输入数量 / 输出数量 / 排除原因 / 保留比例。

## 5.2 Asymmetric Scene Detection（复用 CCS'25）

**Step 1：Rule-based Curvature Classifier**  
计算左右 road boundary 的 curvature difference $\Delta k$，超过阈值 $\Delta k_{\text{thre}} = 0.3$ 且单侧曲率低于 $\bar{k}_{\text{thre}}$ 则标记为 asymmetric。同步输出 asymmetry anchor 集合 $\mathcal{D}$。

目标场景类型：fork / merge / one-side diverging boundary / asymmetric turn。

**Step 2：VLM Refinement（GPT-4o）**  
过滤 false positives（irregular symmetric crossroad / boundary annotation noise）。输出：scene class / road type / asymmetry anchor / reasoning。

## 5.3 Target Sequence Construction

对每个 target frame $t$，构造：

```
[t-W, ..., t-1]    clean warm-up frames（默认 W = 10）
[t]                attack frame（单帧 Camera Blinding）
[t+1, ..., t+L]    clean recovery observation frames（默认 L = 19）
```

**必须先做 Warm-up Convergence Analysis（见 5.4）才能确认 $W = 10$ 是否足够。**

## 5.4 Warm-up Convergence Analysis

在正式实验前，对 clean StreamMapNet 测试不同 warm-up 长度的影响：

$$W \in \{0, 3, 5, 10, 15, 20\}$$

观察指标：mAP / AP_boundary / target-boundary Chamfer / propagated query count / query confidence distribution / temporal state norm。

**判定标准**：若 $W=10$ 时上述指标与 $W=15$、$W=20$ 无统计显著差异，则 $W=10$ 有效；否则增大 $W$ 或限制 target frame 位置（仅选 scene 后段帧）。

## 5.5 Clean-quality Filter

为确保 RecoveryRatio 分母稳定，正式样本需满足以下全部条件：

1. $\text{mAP}^{\text{clean}}_{t} \geq q_{\text{mAP}}$（建议取 validation set asymmetric 场景 mAP 的第 25 百分位）；
2. $\text{AP}^{\text{clean}}_{\text{boundary},t} \geq q_{\text{bd}}$；
3. Target-boundary Chamfer 不超过阈值；
4. Clean prediction 未发生 road straightening（即 clean 条件下不存在 symmetry bias 触发）；
5. Clean recovery window 内 performance 不剧烈震荡（相邻帧 mAP 变化 < 阈值）；
6. Target boundary 在 recovery window 内仍有足够可见性。

**样本分组**（均需报告）：

| 类别 | 处理 |
|------|------|
| Clean correct + Attack wrong | **主分析** |
| Clean already wrong + Attack worse | 单独报告，不混入主分析 |
| Clean unstable | 排除 |
| Low VPA | 单独报告 |
| Insufficient warm-up / recovery | 排除 |

## 5.6 Scene-level Independence Control

**问题**：同一 nuScenes scene 中可能存在多个 target frames，不能当作独立样本。

**处理方式**（二选一，论文中明确说明）：
1. 每个 scene 只选一个 primary target frame（选 clean mAP 最高的帧，避免 cherry-picking）；
2. 使用 scene-level clustered bootstrap，报告 scene-level 置信区间。

**样本量估算**：nuScenes val set 约 150 scenes，asymmetric 比例约 20%，预计可用 asymmetric scenes 约 30–40 个。如采用方案 1，最终主分析样本量约为 **30–40**。该样本量下，bootstrap 95% CI 宽度约为效应量的 ±30%，需要中等效应量（AUC_residue > 0.3 per scene）才能达到统计显著性。  
**如果样本量不足，可补充以下操作**：放宽 asymmetric 定义阈值（但须对比原始阈值的结果），或从 nuScenes trainset 中选取验证子集（需说明 split 处理）。

# 六、攻击设置

## 6.1 主攻击：Camera Blinding

**定位**：在帧 t 施加的 transient physical-effect perturbation，基于 parametric glare approximation（与 CCS'25 一致）。本文不声称完整复现真实光学过程，而是定位为：

> *a controlled one-frame physical-effect perturbation based on the parametric glare approximation used in prior work*

**选择理由**：
- 可在协议层面精确定义"攻击开启/关闭"；
- 不存在 patch 物理消失的现实性问题；
- 不依赖目标模型梯度；
- 与 CCS'25 flashlight attack 机制一致，便于对比。

## 6.2 Camera Blinding 渲染

攻击源固定在 global coordinate $p_{\text{global}}$。每帧投影：

$$p_{\text{cam}} = T_{\text{cam} \leftarrow \text{ego}} \cdot T_{\text{ego} \leftarrow \text{global}} \cdot p_{\text{global}}$$

**注意**：不能直接将 calibrated sensor extrinsic 当作 world-to-camera transform。

渲染步骤：
1. Visibility check（是否在 FOV 内）；
2. 2D image projection；
3. 基于 inverse-square law 的 distance-based intensity approximation；
4. Parametric Gaussian glare rendering；
5. VPA logging（记录每帧的 glare region 面积、中心点、距离）。

## 6.3 Intensity Sensitivity Analysis

不将特定 lumen 值声明为精确物理真值，改为：

$$\text{Intensity} \in \{\text{low}, \text{medium}, \text{high}\}$$

主实验使用 medium intensity；附录报告 low / high sensitivity。

## 6.4 Valid Projection Area（VPA）

**定义**：Camera Blinding 的 VPA 为 glare / blur region 在 target boundary 所在图像区域内的像素面积占比（**不是总图像面积占比**）。

使用 target boundary 所在图像区域作为分母，而非全图，原因：落在天空或远景的 glare 对 boundary prediction 影响极小，面积占比应反映对关键区域的覆盖。

记录：VPA 值 / glare 中心点 / 攻击源与各 camera 的距离。

**VPA 过低处理**：若 VPA < 阈值，标记为 low-visibility sample，单独分析，不直接混入主 TAF 统计。

## 6.5 Adversarial Patch（补充实验，非主线）

**Patch 不用于 recovery curve 主实验**，原因：patch 是实体，不会在一帧后物理消失，因此"patch 停止后的 recovery"缺乏现实对应。

Patch 仅用于：
1. 单帧攻击效果补充（实验组 1）；
2. Transferability 分析（Transfer Patch：MapTR-optimized → StreamMapNet）；
3. Adaptive vulnerability 分析（Adaptive Patch：StreamMapNet-optimized → StreamMapNet）；
4. 在 patch 连续可见条件下的 temporal effect 分析（patch 固定在 global coordinate，随车辆运动重投影）。

**Transfer Gap 指标**：

$$\text{TransferGap} = \text{Effect}_{\text{adaptive}} - \text{Effect}_{\text{transfer}}$$

若 transfer patch 无效但 adaptive patch 有效，说明问题在 transferability，而非 StreamMapNet 本身鲁棒。

# 七、核心指标

## 7.1 Paired Recovery Ratio

$$\text{RecoveryRatio}_i = \frac{\text{Metric}^{\text{attack}}_{t+i}}{\text{Metric}^{\text{clean}}_{t+i}}$$

适用于越高越好的指标（mAP、AP_boundary）。  
对于越低越好的指标（Chamfer Distance），使用：

$$\Delta\text{CD}_i = \text{CD}^{\text{attack}}_{t+i} - \text{CD}^{\text{clean}}_{t+i}$$

以及归一化版本（附录）：

$$\text{ChamferRatio}_i = \frac{\text{CD}^{\text{attack}}_{t+i}}{\text{CD}^{\text{clean}}_{t+i} + \epsilon}$$

## 7.2 Recovery Frame Count（RFC）

给定阈值 $\tau$ 和连续窗口 $K$：

$$\text{RFC} = \min\, i \quad \text{s.t.} \quad \text{RecoveryRatio}_i, \text{RecoveryRatio}_{i+1}, \text{RecoveryRatio}_{i+2} \geq \tau$$

默认：$\tau = 0.9$，$K = 3$。

附录报告：$\tau \in \{0.8, 0.9, 0.95\}$。

若观测窗口 $L$ 内未恢复，标记为 **censored sample**，不简单丢弃。RFC 作为下界，AUC_residue 作为主统计指标。

## 7.3 Attack Propagation Depth（APD）

$$\text{APD} = \sum_{i=1}^{L} \mathbf{1}(\text{RecoveryRatio}_i < \tau)$$

APD 表示攻击停止后仍低于恢复阈值的帧数总计。

## 7.4 Residual AUC（主统计指标）

$$\text{AUC}_{\text{residue}} = \sum_{i=1}^{L} \max\left(0,\, 1 - \text{RecoveryRatio}_i\right)$$

对 Chamfer：

$$\text{AUC}_{\text{CD}} = \sum_{i=1}^{L} \max\left(0,\, \Delta\text{CD}_i\right)$$

**AUC_residue 是主统计检验指标；RFC 作为直观解释指标。**

## 7.5 Target-boundary Chamfer（Target-BD-CD）

单独计算攻击目标 boundary 的 Chamfer Distance：

$$\text{CD}(B^{\text{pred}}_{\text{target}},\, B^{\text{gt}}_{\text{target}})$$

报告：attack frame / recovery frames / clean paired delta / AUC_CD / per-scene 分布。

## 7.6 Road Straightening Success（RSS）

$$\text{RSS} = \mathbf{1}\left[\text{CD}(B^{\text{pred}}, B^{\text{straight}}) < \text{CD}(B^{\text{pred}}, B^{\text{gt}})\right]$$

predicted boundary 更接近错误 straight reference 则 RSS = 1。

报告：attack frame RSS / recovery frame RSS / RSS recovery curve / persistent RSS rate。

## 7.7 Relative Damage Ratio（RDR）

$$\text{RDR} = \frac{\text{Metric}_{\text{clean}} - \text{Metric}_{\text{attack}}}{\text{Metric}_{\text{clean}}}$$

用于单帧攻击对比（实验组 1）。

## 7.8 Comparative Vulnerability Difference（CVD）

$$\text{CVD} = \text{RDR}_{\text{Stream}}(1) - \text{RDR}_{\text{MapTR}}(1)$$

CVD > 0 表示 StreamMapNet 瞬时比 MapTR 更脆弱。CVD 与 RFC 联合解读：

| CVD | RFC | 解释 |
|-----|-----|------|
| > 0 | ≥ 2 | 最强结果：瞬时更脆弱且有 residue |
| < 0 | ≥ 2 | 瞬时可能更稳，但错误进入 state 后会残留 |
| > 0 | 0–1 | 只有瞬时脆弱性，temporal 贡献弱 |
| < 0 | 0–1 | 主线基本失败，转 self-healing |

## 7.9 Planner-level Safety Metrics

使用与 CCS'25 等价的 Hybrid A* planner，paired 设置（same start / goal / route / planner parameters）。

指标：
- **UGR**：Unreachable Goal Rate
- **UPTR**：Unsafe Planned Trajectory Rate
- **Unsafe window length**（帧数）
- **Unsafe travel distance**：若 RFC = $r$ frames，2 Hz，城市速度 30 km/h = 8.33 m/s，则 $D = 8.33 \times 0.5r$ 米
- **Cumulative planner risk**：recovery window 内 UPTR 的帧数加权平均
- **Paired delta**：$\Delta\text{UGR} = \text{UGR}^{\text{attack}} - \text{UGR}^{\text{clean}}$，$\Delta\text{UPTR} = \text{UPTR}^{\text{attack}} - \text{UPTR}^{\text{clean}}$

**时间窗口匹配约束**（v6.1 遗漏的关键点）：  
planner risk 只在车辆仍处于需要通过 asymmetric 场景的时间窗口内有意义。必须报告：recovery window 内有多少比例的帧，车辆在路径规划上仍需要经过 asymmetry anchor 附近。若大多数 recovery 帧中车辆已通过 fork/merge 点，则 planner risk 增量的实际意义有限，需在论文中明确说明。

**措辞约束**：使用"planner-level risk"，不声称"商业 AV 一定碰撞"。

## 7.10 Temporal Amplification Metrics

**正确的计算基准**（修正 v6.1 中的潜在混淆）：

Independent single-frame attack 的定义：对每个帧 $t+j$（$j = 0, ..., N-1$），**各自从 clean warm-up 重新开始**，只攻击该单帧，再观察 t+j 帧的 mAP drop。这样每次都是从 clean state 出发，与 continuous attack 的起点不同，因此 TAF_ind 衡量的是"连续攻击相比独立单帧攻击是否有超加性效果"。

**Ratio Form**（用于直观展示）：

$$\text{TAF}_{\text{state}}(N) = \frac{\Delta\text{Metric}_{\text{keep-state}}(N)}{\Delta\text{Metric}_{\text{reset-state}}(N) + \epsilon}$$

$$\text{TAF}_{\text{ind}}(N) = \frac{\Delta\text{Metric}_{\text{continuous}}(N)}{\frac{1}{N}\sum_{j=0}^{N-1}\Delta\text{Metric}_{\text{single},j} + \epsilon}$$

**Additive Interaction Form**（主统计检验，无分母过小风险）：

$$\text{Interaction}_{\text{state}} = \Delta\text{Metric}_{\text{keep-state}} - \Delta\text{Metric}_{\text{reset-state}}$$

$$\text{Interaction}_{\text{ind}} = \Delta\text{Metric}_{\text{continuous}} - \frac{1}{N}\sum_{j=0}^{N-1}\Delta\text{Metric}_{\text{single},j}$$

**注意**：reset-state 和 keep-state 的 clean baseline 不同（reset-state 丧失 temporal context，clean mAP 本身更低）。因此 TAF_state 的 ratio 比较存在基线不等价问题，**只作辅助展示**，不作主要统计结论；主结论使用 Interaction_state，即绝对 delta 差值。

# 八、错误 Query 传播的操作性定义

## 8.1 Wrong Target Query（帧 t）

在 attack frame $t$，若某个 predicted boundary query 同时满足：

1. 与 attack target boundary 匹配（Hungarian matching）；
2. Predicted polyline 更接近错误 straight reference：$\text{CD}(B^{\text{pred}}, B^{\text{straight}}) < \text{CD}(B^{\text{pred}}, B^{\text{gt}})$；
3. 与 GT diverging boundary 偏离明显（Chamfer > 阈值）；
4. Confidence 超过传播候选阈值：$\text{Conf}(B^{\text{pred}}) > \theta_{\text{conf}}$；

则标记为 **wrong target query**。

## 8.2 Propagated Wrong Query（帧 t+1）

若 wrong target query 被 StreamMapNet 的 query propagation module 选中，并在帧 t+1 存在对应 propagated query，则定义为 **propagated wrong query**。

对应关系确认方式（优先级依序）：
1. Query ID（若模型暴露）；
2. Propagation candidate list；
3. Hungarian matching；
4. Embedding cosine similarity > 阈值；
5. Predicted polyline 几何连续性。

## 8.3 Persistent Wrong Query（帧 t+i，$i \geq 2$）

若 propagated wrong query 在帧 t+i 仍满足：
1. Embedding 与 attack-frame wrong query 高相似；
2. Predicted polyline 仍更接近 wrong reference 而非 GT；
3. 或仍显著偏离 GT target boundary；

则定义为 **persistent wrong query**。

**强证据判定条件**：
```
same propagated candidate
  + embedding cosine > 0.85
  + geometry remains closer to wrong reference than GT
```

## 实验组 3（Phase 4）：Temporal Residue 主实验

### 攻击
Camera Blinding，$N_{\text{attack}} = 1$。

### 实验条件

| 条件 | 描述 |
|------|------|
| clean + keep-state | 正常 clean 时序（主 clean baseline） |
| attack + keep-state | 原始攻击 + 时序传播（主 attack 条件） |
| clean + reset-all | reset 操作本身对 clean 的影响（DID 控制组） |

| attack + reset-query | 验证 query propagation channel |
| clean + reset-BEV | reset BEV 对 clean 的影响 |
| attack + reset-BEV | 验证 historical BEV fusion channel |

### Difference-in-Differences 分析

**DID 使用绝对 delta，避免基线不等价问题**：

$$\text{DID}_{\text{reset}} = \underbrace{(\text{Attack}_{\text{keep}} - \text{Clean}_{\text{keep}})}_{\text{keep-state damage}} - \underbrace{(\text{Attack}_{\text{reset}} - \text{Clean}_{\text{reset}})}_{\text{reset-state damage}}$$

DID > 0 表示 temporal state 传播了额外损伤，而非 reset 操作改变了模型分布。

**基线不等价校正**：同时报告 $\text{Clean}_{\text{keep}}$ 与 $\text{Clean}_{\text{reset}}$ 的 clean mAP 差距，作为 DID 解读的参考。若 clean mAP 差距大（>5%），则 DID 结论需额外说明。

# 十、统计分析要求

## 10.1 每个核心指标必须报告
mean / median / standard deviation / P75 / P90 / bootstrap 95% CI / per-scene 分布 / censored ratio（未恢复比例）。

## 10.2 Bootstrap 策略
**使用 scene-level clustered bootstrap**，避免同一 scene 多帧被当作独立样本。如每个 scene 只选一个 primary target frame，则直接使用 standard bootstrap。

## 10.3 主统计检验
- **AUC_residue**：paired bootstrap / Wilcoxon signed-rank test；
- **DID**：paired bootstrap；
- **Interaction_state / Interaction_ind**：paired permutation test；
- 显著性水平：$p < 0.05$，双侧。

## 10.4 Censored Samples 处理
对 $L$ 帧内未恢复样本：
- 报告 censored ratio；
- RFC 作为下界（而非精确值）；
- 可选：Kaplan-Meier recovery curve；
- AUC_residue 作为非阈值主指标，不受截尾影响。

## 10.5 样本量与检验 Power
在正式实验报告中，需说明：目标样本量 $n$、预期效应量（基于 Phase 1 预实验估计）、对应的检验 power（建议 ≥ 0.8）。若样本量不足，明确说明结论的局限性。

# 十五、核心贡献表述

1. 首次证明 streaming online HD map construction 在 transient symmetry-bias physical attacks 下存在 temporal residue，即攻击停止后 temporal state 持续输出错误地图预测。

3. 通过 temporal state reset ablation 定量证明 propagated queries 和/或 historical BEV features 是 residue 的传播通道。
4. 量化 planner-level safety risk 在 recovery window 内的持续增量，报告 unsafe travel distance 估算。
5. 提供 preliminary mitigation：通过检测 wrong boundary query 传播并选择性 reset temporal state 可部分缓解 residue（可选）。

**路径 B（H1 不成立）**：

1. 首次系统分析 streaming online HD map construction 在 transient symmetry-bias perturbations 下的时序鲁棒性。
